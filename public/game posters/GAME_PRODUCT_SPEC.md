## 4. Game Unlock & Purchase Rules

1. A group unlocks only when all six PC components meet its minimum build requirement.
2. Unlocking a group does not automatically purchase its games.
3. Every game inside a group must be purchased individually using in-game currency.
4. Standalone games are purchased individually and do not belong to any group.
5. A game can only be played when the PC meets its minimum hardware requirement.
6. Higher-tier PCs can run games from all lower build tiers.
7. Purchased games remain permanently available in the player's game library.
